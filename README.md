# TeoCat
Repositório de material sobre teoria das categorias (Repository of material on category theory)

Este repositório contém alguns arquivos que podem ser usados no Notebook Gemini para direcioná-lo a produzir melhores explicações, provas e diagramas. Estes arquivos podem ser adaptados a outros aplicativos de IA. A diferença é que no Notebook Gemini existe um "Studio" capaz de mostrar imagens, vídeos e outras coisas. 

# Exemplo de uso:
Para fazer a pergunta "Faça a prova de que $A\times (B\times C) \cong (A\times B)\times C$", adicione o arquivo scolor.txt como fonte (source) no Notebook Gemini (NG), além de outros materiais sobre Teoria das Categorias. Então, peça para o NG usar o arquivo scolor.txt para fazer a resposta. Então, a pergunta ficaria assim:

Prove that $A\times ( B\times C) \cong (A \times B)\times C$. Use the recommendations of the source scolor.txt. 

Pode fazer a pergunta em Português também, mesmo sabendo que scolor.txt está em Inglês.
